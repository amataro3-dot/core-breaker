## 0. このゲームについて

- ゲーム名: **CORE BREAKER**(コアブレイカー)
- ジャンル: 横から見た2Dのサンドボックス対戦(テラリア風)。地形を掘る・壊す・置く

- 見た目: サイバーパンク(ネオン)
- **スマホ(縦持ち)のみ**。PC版は作らない
- Muddy's Games の1本として公開する

## 3. 人数・チーム

- 最大8人。**シアンチーム4人 vs ピンクチーム4人**
- 空いた枠はAI(コンピューター)が埋める。1人でも遊べる
- 入室前に好きな名前を入れる(他のゲームと同じ)
- ロビーでチームを選ぶ。部屋を作った人がチーム分けを調整できる

## 4. マップ

- **固定マップ**(試合ごとに同じ形)。横長
- **上下2層**
  - 上の層(地上): 見晴らしがよく、撃ち合いになりやすい広い道
  - 下の層(地下): 狭いトンネル。見通しが悪く、待ち伏せや奇襲向き
- 左端にシアンの陣地とコア、右端にピンクの陣地とコア
- **どちらの層からも相手の陣地に行ける**
- 層の間は、ハシゴや縦穴でつながっている。床を掘ったり爆破したりすれば、新しい通り道も作れる
- 試合中に壊れた地形は、試合が終わるまで元に戻らない

**ブロックの種類(最初の案)**

| 種類 | 性質 |
|---|---|
| 通常ブロック | 掘れる・爆破で壊れる。支えがないと崩れる |
| 硬いブロック | 爆弾でしか壊れない |
| 岩盤 | 壊れない。マップの外枠と一番下 |
| 砂 | 下に何もないと落ちる。ななめにもくずれて山になる |
| 水 | 流れて低いところにたまる。量は増えも減りもしない。中では動きが遅くなる |
| ハシゴ | 掘れない・崩れない。支えになる(地面を縦に切っているため) |

## 5. 物理

2種類の物理を使い分ける。

**A. ブロックの物理(ゲームの判定に使う)**
- 砂は落ちる、水は流れて広がる、支えを失った足場は崩れる
- 部屋を作った人(ホスト)の端末が計算して、変わったブロックだけを全員に送る

**Aの細かいルール(v0.2で決定・実装)**
- 計算は1秒に10回。落ちる物は1回に1段ずつ動く
- **崩れる**: 通常ブロックは、支え(硬いブロック・岩盤・コア・ハシゴ)に上下左右でつながっていれば崩れない。つながっていない固まりは、**固まりごと1段ずつ落ちて、下に積もる**(消えない)。下に空気か水がないと止まる
- **砂**: 下が空いていれば落ちる。ふさがっていれば、ななめ下が空いている方へくずれる。砂は支えにならない
- **水**: 量は変わらない。下が空いていれば落ちる。ふさがっていれば、横8マス以内の「低いところ」へ1マスずつ流れる。上に水が乗っている水は、横の空きに押し出される。ハシゴは水を通さない
- 落ちてくる物や砂は、水と入れかわる(水が上に押し出される)
- 落ちてきた物に埋まったプレイヤーは、いちばん近い空いた場所に押し出される(ダメージはステップ4で決める)
- 置いたブロックは通常ブロックになる。宙に置くと落ちる

**B. 吹っ飛ぶ物理(主に見た目)**
- 爆発の破片、崩れる瓦礫が飛び散る
- 各スマホが自分で描くだけで、同期しない(軽くて派手にできる)
- 転がって当たり判定がある物(木箱など)を入れる場合は、数を絞ってホストが動かす(後回し)

## 6. 勝ち方: コア破壊モード(基本モード)

- 各チームのコアは**体力1000**
- **相手のコアを先に壊したチームの勝ち**
- 制限時間は**5分**。時間切れのときは、コアの残り体力が多いほうの勝ち(同じなら引き分け)
- コアは最初、ブロックの壁に囲まれて埋まっている。掘るか爆破して、むき出しにしないと攻撃できない
- 上の層からも下の層からも近づける位置に置く
- **爆弾はコアに大ダメージ、銃は小ダメージ**
- 守る側は、自分のコアの近くにいると、少しずつ**修理**できる
- コアの周りが崩れると、瓦礫や砂でまた埋まることがある

**あとで足すモード**
- 拠点到達: 相手の拠点に入って、占領ゲージ(3秒)をためたら勝ち
- 倒した数: 制限時間内に、相手を多く倒したチームの勝ち

## 7. プレイヤー

- 体力100。0になるとやられて、**5秒後に自陣で復活**
- ダッシュ: 短い距離をすばやく移動。数秒のクールダウン
- 水の中では動きが遅くなる
- 落下ダメージは、最初はなし(あとで検討)

## 8. 持ち物(4つを切り替える)

| 持ち物 | 使い方 | 最初の案 |
|---|---|---|
| 銃 | 狙った方向に撃つ(初期装備のピストルは離して1発) | 人に小〜中ダメージ、コアに小ダメージ、ブロックは壊さない |
| 爆弾 | 放物線で投げる。数秒で爆発 | 周りのブロックを壊す、人とコアに大ダメージ。所持数に上限、時間で補充 |
| つるはし | 隣のブロックを掘る | 通常ブロックと砂を壊す。掘ったブロックは自分の手持ちになる |
| ブロック | 狙った場所に置く | 手持ちの数だけ置ける(最初10個、上限20個)。空気の所だけ(水の中・人の重なる所は不可) |

- 掘る・置くが届くのは、体の真ん中から4.5ブロック以内
- **画面タップ**でも掘る・置くができる(ブロックをタップ=掘る、空きをタップ=置く)。v0.2の仮の操作だったが、v0.3でも残すことにした

**持ち物の細かいルール(v0.3で決定・実装。数字は目安)**
- **銃**(v0.3。v0.4でピストルに変更、下を見る): 倒している間、1秒に6発。弾の速さ40マス/秒、0.6秒で消える(約24マス)。ブロックで止まる(壊さない)。照準線が出る。人・コアへのダメージはステップ4
- **爆弾**: 最大3個、8秒で1個補充。倒すと投げる軌道(黄色の点)が出て、離すと投げる。強く倒すほど遠く(速さ7〜19)。はずんで転がり、2秒で爆発(赤いランプが点滅、最後は速く)。半径2.5マスの通常ブロック・砂・硬いブロックを壊す(岩盤・コア・ハシゴ・水は残る)。爆風で近くの人が飛ばされる(3.5マス以内)。画面がゆれる
- **つるはし**: 倒している間、倒した方向のいちばん近いブロック(2.5マス以内。空気・水・ハシゴは通り抜けて探す)を0.25秒に1個掘る。黄色の枠が出る。掘れないブロックは赤い枠
- **ブロック**: 倒した向き・強さで、胸の高さから1〜3マス先の空いているマスに枠が出て、離すと置く。ブロック・水・ハシゴの手前で止まる。置けないときは赤い枠
- **軽くタップ**: 銃は向いている方へ1発、つるはしは向いている方を掘る、ブロックは向いている方の足もとに置く、爆弾は向いている方へ軽く投げる
- **倒してから真ん中にもどして離す**と、使うのをやめる(爆弾・ブロック)
- 持ち物ボタンに、爆弾とブロックの残り数を表示
- 掘ると小さな破片、爆発で光の輪・火花・大きな破片が飛ぶ(見た目だけ)

**銃(v0.4で変更)**
- **初期装備はピストル**: 狙っている間は照準線(撃てるまでの間はうすく)。**離したら1発**、次に撃てるまで0.35秒。タップなら向いている方へ1発
- **銃は種類を増やす予定**。どんな種類にするか、どう手に入れるかは、これから相談する

**体力・コア・試合のルール(v0.4で決定・実装。数字は目安)**
- プレイヤー: 体力100。頭の上に名前と体力バー、画面の左上に自分のHP。0でやられて、5秒後に自分の陣地で復活(画面に残り秒数)
- **ピストル**: 人に20(5発で倒れる)、コアに10。銃は仲間には当たらない
- **爆弾**: 人に最大60(中心から1マス以内で最大、3.2マスまで)、**自分にも仲間にも当たる**。コアに最大150(コアの四角から1マス以内で最大、3マスまで)。**自分のチームのコアには当たらない**
- コア: 体力1000。弾がコアのブロックに当たる、または爆風が届くとダメージ。当たると白く光り、残り3割以下でちらつく。壊れるとコアのブロックが消えて大爆発
- **修理**: 自分のコアの四角から5マス以内にいると、1秒に10回復(コアのまわりに緑の輪)。埋まったコアの真上の地面からも届く
- 試合: 5分。残り30秒でタイマーが赤くなる。時間切れはコアの残り体力で判定(同じなら引き分け)
- 終わったら結果画面(WIN / LOSE / DRAW、両方のコアの残り)と「もう一度」ボタン。マップも全部元どおりにして新しい試合
- ダメージを受けると数字が浮かび、自分なら画面のふちが赤く光る
- 落ちてきたブロックに埋まってもダメージなし(押し出すだけ)
- **練習用の的**(v0.4のみ): ピンク3体(地上2、地下トンネル1)。相手陣地の近くを左右にうろうろ。撃ち返さない。倒すと5秒で復活。ステップ5でAIに置きかえる

**速さとマップ(v0.4.1で変更)**
- キャラの動き(歩く、ハシゴ、落ちる、泳ぐ)を約7割の速さに。歩く速さは1秒に約6マス。ジャンプの高さは約3マスのまま、ふんわり跳ぶ(重さも0.7×0.7にしたため)
- 照準線は、指の向きに少し遅れてなめらかについてくる(約0.15秒で追いつく)。全部の持ち物に効く。離したときは、画面に出ていた照準線の向きで使う。すばやくはじいて離したときは、指の向きで使う
- マップの横幅を160→**120ブロック**に(高さ48は同じ)。並びは同じまま縮めた: ハシゴは端から11・30・59マス目、地下の水たまりは45〜50、砂は19〜22(地面の中)と38〜41(トンネルの天井の上)、物陰24、硬い物陰36〜37、見張り台49〜52と55〜59
- ミニマップは10〜37段目だけを映す(横幅が狭くなっても縦に大きくならないように)
- 弾の速さ、爆弾の投げ方・爆発は変えていない

**ジャンプ(v0.3で変更)**: 左スティックを上に倒している間は、着地するたびにまた跳ぶ(ピョンピョン)

## 9. 操作

- **左スティック**: 左右に移動。上に倒すとジャンプ(倒している間は跳び続ける)、ハシゴでは上下に移動
- **右スティック**: 狙う方向に倒して、離すと使う
  - 銃: 照準線が出る。倒している間は自動で連射
  - 爆弾: 投げる軌道が出る。強く倒すほど遠くへ。離すと投げる
  - つるはし: 倒した方向の隣のブロックを掘る
  - ブロック: 置く場所の枠が出て、離すと置く
  - 軽くタップしただけなら、向いている方向にそのまま使う
- **ダッシュボタン**: 2本のスティックの間
- **持ち物の切り替え**: スティックの上に4つ並んだボタン

## 10. 画面(縦持ち)

上から順に:
1. **HUD**: 左に自チーム(シアン)のコア体力、真ん中に残り時間、右に相手(ピンク)のコア体力
2. **ミニマップ**: マップ全体の上下2層、両方のコア、仲間と敵の位置。今見えている範囲を枠で表示
3. **ゲーム画面**: カメラは自分を追いかける。手持ちのブロック数を左下に表示
4. **操作部**: 持ち物4つ、左スティック、ダッシュ、右スティック

## 12. オンラインの仕組み

- **ルーム方式**: 作った人が4桁のコードを発行、他の人はコードで入る。最大8人
- **ホスト方式**: 部屋を作った人の端末が「審判」
  - ホストが決めるもの: ブロックの物理、コアの体力、爆弾の爆発、復活、時間、勝敗、AIの動き
  - 各自が送るもの: 自分の位置と向き(1秒に10回くらい)、使った持ち物
- 他の人の動きは、受け取った位置の間をなめらかにつないで表示する(補間)
- **銃の当たり判定は撃った人の画面で決める**(「当たったのに!」を防ぐため)
- 地形は、変わったブロックだけを送る(全部は送らない)
- 回線が切れた人は、Firebaseの切断検知(onDisconnect)で分かるようにする。その人の枠はAIが引き継ぐ
- 終わった部屋のデータは消す
- データの置き場所は `rooms/部屋ID` の下。ログイン済み(匿名認証)なら読み書き可、`rooms` 全体の読み取りは不可

## 13. AI

- 空いた枠を埋める。役割を分ける(攻め、守り、地下ルート担当など)
- 攻め: 相手のコアに向かい、壁があれば掘る・爆破する
- 守り: 自分のコアの近くで敵を撃ち、修理する
- 強さは最初は弱めにして、あとで調整
